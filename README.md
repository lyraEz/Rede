# RedeToons

Extensão RedeToons para assistir filmes, séries e animes no Aniyomi e no AniZen. Esta versão corrige o APK da extensão publicado no [repositório da Awerkori](https://github.com/Awerkori/anime-extensoes) para o domínio atual, `redetoons.email`.

## Adicionar a loja

Copie o endereço correspondente ao seu aplicativo e cole na opção de adicionar loja ou repositório de extensões.

**Aniyomi**

```text
https://raw.githubusercontent.com/lyraEz/Rede/repo/store-v2-1000-7.json
```

**AniZen**

```text
https://raw.githubusercontent.com/lyraEz/Rede/repo/index.min.json
```

Depois, atualize a lista de extensões e instale **RedeToons**.

## APK

Versão atual: **1000-7**. O APK também pode ser [baixado diretamente](https://raw.githubusercontent.com/lyraEz/Rede/repo/apk/aniyomi-pt.redetoons-v1000-7-r1.apk).

Se a versão anterior da RedeToons estiver instalada, desinstale-a antes de instalar esta. A assinatura do APK é diferente da usada pela extensão anterior.
